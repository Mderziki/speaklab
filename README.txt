SpeakLab SEO pack

Files
- index.html: updated homepage with canonical tag, Guides links, and internal-linking section.
- styles.css / script.js: copies of your existing site assets.
- seo-content.css: styles for the Guides hub and article pages.
- guides/index.html: SEO content hub.
- guides/*.html: nine focused SEO pages.
- sitemap.xml: includes homepage, Guides hub, and all guide URLs.
- robots.txt: allows crawling and points to sitemap.
- seo-keyword-map.csv: page-to-keyword mapping.

Deployment
1. Upload all files/folders while preserving the folder structure.
2. Make sure the homepage is served as /index.html (or rename/merge as needed).
3. Submit https://speaklab.live/sitemap.xml in Google Search Console.
4. Request indexing for the Guides hub and the highest-priority pages first:
   /guides/ai-public-speaking-coach.html
   /guides/public-speaking-simulator.html
   /guides/public-speaking-practice.html
   /guides/public-speaking-skills.html
5. Add original screenshots, examples, practice clips, or real product observations as SpeakLab develops. Those additions will make the pages more distinctive and useful.
